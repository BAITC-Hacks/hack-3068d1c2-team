# Есть дефект или нет

Решение для трека 02 «Компьютерное зрение». Скрипт получает путь к изображению и печатает `OK` либо `DEFECT`.

## Идея

Изображение уменьшается до 256 пикселей по большей стороне. Затем считается доля красных пикселей: у такого пикселя канал `R` не ниже 140 и как минимум в 1.5 раза больше каналов `G` и `B`. Если доля красных пикселей составляет 10% или больше — это `DEFECT`, иначе `OK`.

В репозитории есть два примера: `ok.png` (нормальный кадр) и `defect.png` (кадр с красным дефектом). Их можно пересоздать командой `python make_images.py`.

## Запуск

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
python check.py ok.png
python check.py defect.png
```

Ожидаемый результат:

```text
OK
red_ratio=0.000 threshold=0.10

DEFECT
red_ratio=0.223 threshold=0.10
```

Для проверки обоих кадров:

```bash
python -m unittest test_check.py
```

## Ограничения

Это демонстрационное пороговое правило, а не обученная модель. Оно хорошо показывает кейс с красным дефектом, но может ошибаться на обычных объектах с большой красной областью или на дефектах другого цвета.
