# Есть дефект или нет

Трек 02, компьютерное зрение. Скрипт берёт путь к картинке и печатает OK или DEFECT.

## Как работает

Картинка уменьшается до 256 пикселей по длинной стороне, затем считается доля "красных" пикселей: канал R выше 110 и минимум в 1.6 раза больше G и B. Если доля не меньше 0.10, это DEFECT, иначе OK. Модель не используется, правило чисто пороговое.

## Запуск

Нужен Python 3 и Pillow.

```
pip install pillow
python check.py ok.png
python check.py defect.png
```

## Что получилось

```
$ python check.py ok.png
OK
red_ratio=0.000 threshold=0.10

$ python check.py defect.png
DEFECT
red_ratio=0.179 threshold=0.10
```

Оба тестовых кадра классифицируются верно.

## Ограничения

Красный цвет это единственный признак. Любая красная деталь в норме даст ложный DEFECT, а дефект другого цвета скрипт не заметит. Порог 0.10 подобран под тестовые кадры.
